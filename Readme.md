# korp-mono-fill-gen

Accompanying library to replace the strings `[[[GEN:<string>:::<original_base64_analysis>]]]` in `korp_mono/` files generated by `korp-mono-rs`,
with the generated lemmas.

This repo contains a rust library, which is used by `korp-mono-rs`, but
for debugging, it also contains a binary which can be useful for debugging
errors occuring on this lemma generation.

In the generated `korp_mono/` files from `korp-mono-rs`, there are
wordforms in the analyzed files for which a lemma cannot be extracted.
These lemmas will instead of looking like an actual lemma in the files,
look like `[[[GEN:<string>:::<original_base64_analysis>]]]`, where
`<string>` is the strong to be sent to the _generator fst_, and
`<original_base64_analysis>` is the original analysis in giellacg format from the analyser, base64-encoded.

This script finds all these lemmas that will need to be generated, and looks
them up with the generator, and replaces the contents of the `korp_mono/` files
with the generated lemmas.
